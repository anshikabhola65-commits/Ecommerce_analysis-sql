# E-Commerce Sales & Customer Analysis Using MySQL

## 📌 Project Overview
This project analyzes e-commerce sales and customer data using MySQL. The goal is to understand sales performance, identify top-performing products and customers, and explore customer purchasing patterns using SQL queries.

## 🎯 Objectives
- Calculate total revenue from delivered orders.
- Analyze revenue by product category.
- Identify the highest-spending customers.
- Find products that have never been ordered.
- Analyze monthly sales revenue.
- Count orders placed by each customer.
- Analyze the number of customers in each city.
- Identify top products based on revenue.
- Explore order values and repeat customer behavior.

## 🛠️ Tools & Technologies
- **MySQL** — Database management and SQL analysis
- **MySQL Workbench** — Writing and executing SQL queries
- **SQL** — Data retrieval, filtering, joining, and aggregation

## 🗂️ Database Structure
The project contains four tables:

| Table | Description |
|---|---|
| `customers` | Stores customer details, including names, cities, and countries. |
| `products` | Stores product names, categories, and prices. |
| `orders` | Stores order dates, customer IDs, and order statuses. |
| `order_items` | Stores products included in each order, quantities, and selling prices. |

## 🔍 SQL Concepts Used
- `SELECT` and `WHERE`
- `ORDER BY` and `LIMIT`
- Aggregate functions: `SUM()`, `COUNT()`, and `AVG()`
- `GROUP BY` and `HAVING`
- `INNER JOIN` and `LEFT JOIN`
- Subqueries
- Date-based analysis
- Revenue calculations
